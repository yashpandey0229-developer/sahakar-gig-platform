## 🌟 The Problem vs. Our Cooperative Solution

| Metric / Dimension | Traditional Aggregators (Urban Company, Uber, TaskRabbit) | **SahakarGig (SIH26089 Cooperative Platform)** |
| :--- | :--- | :--- |
| **Platform Commission** | **25% – 35% extracted** from worker earnings | **Capped 5% operating overhead** solely for server IT costs |
| **Worker Direct Take-Home** | 65% – 72% | **88% Net Direct Worker Payout** |
| **Social Security & Healthcare** | 0% (Workers are treated as independent contractors) | **7% Auto-contributed into Cashless Family Health Pool** |
| **Surplus & Profit Distribution** | 100% to Private Venture Capitalists / Shareholders | **100% Surplus returned to Workers as Patronage Dividends** |
| **Account Bans & Suspensions** | Arbitrary algorithmic de-platforming | **3-Member Peer Jury Redressal Chamber** |
| **Accessibility for Blue-Collar** | Complex English-first smartphone apps | **Multilingual Voice Assistant (Web Speech in Hindi/Regional)** |
| **National Integration** | Zero government alignment | **Direct Bridge to PACS (Primary Agricultural Credit Societies)** |

## 🏗️ 4 Role-Based Portals in One App

1. **🏡 Customer Portal**:
   - Transparent price breakdown with 100% audit (Worker share vs. Welfare fund vs. Server ops).
   - Real-time radar dispatch with nearest verified artisan matching.
   - Dual-Key security OTPs (Job Start OTP + Job Completion OTP).
   - Live Leaflet GPS route tracking with ETA countdown.

2. **🧰 Worker (Sahakari Partner) Portal & PWA**:
   - Voice-assisted Hindi/English job notifications.
   - Fair-rotation allocation score preventing rating monopolies.
   - Step-by-step turn-by-turn job execution flow with OTP verification.
   - **Cooperative Wallet**: Liquid cashout + Accrued Patronage Dividends + Welfare Points.

3. **⚖️ Cooperative Board Governance Portal**:
   - Democratic policy voting (1 Worker = 1 Vote) on tariffs, subsidies, and safety rules.
   - Collective Welfare Reserve fund manager and hospitalization claim settlements.
   - Peer Jury Arbitration Chamber for fair dispute redressal.

4. **🏛️ Ministry of Cooperation Analytics**:
   - National district heatmaps and PACS integration metrics.
   - Economic impact index (+38.4% worker hourly uplift).
   - Real-time statutory audit export.

## 🚀 Quick Start & Local Run

```bash
# 1. Clone or navigate into the project directory
cd sahakar-gig-platform

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

## ☁️ Deployment Instructions

### One-Click Deploy on Vercel:
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```

### One-Click Deploy on Render / Netlify / Cloudflare Pages:
- **Build Command**: `npm run build`
- **Publish Directory**: `dist`
- **Node Version**: `20.x` or `22.x`
